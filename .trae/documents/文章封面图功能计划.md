# 文章封面图功能计划

## 一、Summary（目标）

为文章管理增加「封面图」字段：
1. 后台支持手动上传封面图（复用现有 `/api/uploads` 上传能力），编辑时可见预览、可移除、也可直接粘贴图片 URL。
2. 前台渲染时根据是否设置了封面图展示不同效果（用户已确认）：
   - **有封面**：文章列表卡片显示封面图；文章详情页顶部显示大图封面。
   - **无封面**：封面图片块整体隐藏（卡片只显示文字，不保留空占位）。

## 二、Current State Analysis（现状分析）

- 数据模型：`Article`（[schema.prisma](file:///d:/frontProjects/agent/smart-blog-agent/prisma/schema.prisma#L114-L128)）目前无封面字段。
- 文章库：`src/lib/articles.ts` 定义 `ArticleListItem` / `ArticleInput`，`mapArticle` / `createArticle` / `updateArticle` 负责字段映射与读写。
- API：`src/app/api/articles/route.ts`（POST）、`src/app/api/articles/[id]/route.ts`（GET/PATCH/DELETE）透传文章字段。
- 后台 UI：`src/components/admin/article-editor-dialog.tsx` 编辑弹窗、`src/app/admin/articles/page.tsx` 文章列表。
- 上传能力：已有 `/api/uploads`（上传返回 `{ url: "/api/uploads/:id" }`），`/api/uploads/[id]` 负责回显，可直接复用。后台设置页（[settings/page.tsx](file:///d:/frontProjects/agent/smart-blog-agent/src/app/admin/settings/page.tsx#L212-L257)）已有「头像预览 + 上传按钮 + URL 输入框」的可参考交互。
- 前台渲染：`src/lib/theme/content-renderer.ts` 中 `ArticleData`（L5-L14）无封面字段；`dynamic-articles` 列表数据映射（L672-L678）构建 title/excerpt/date/category/link；`renderListField`（L758-L831）按 `data-map` 填充文本；`article-body` 详情渲染（L681-L711）按 `data-map` 填充 title/date/category/tags/meta/body。
- 主题生成：`src/agents/theme-agent.ts`（L389）约束「封面/头图占位类只能用于网格/多列卡片容器内」，详情页不生成封面类（L363-L364）。

## 三、Proposed Changes（改动方案）

### 1. 数据层：新增字段 + 迁移
- **prisma/schema.prisma**：`Article` 模型增加
  ```prisma
  coverImage String? @map("cover_image")
  ```
- 执行迁移：`npx prisma migrate dev --name add_article_cover_image`（生成迁移 SQL 并更新生成的 Prisma client）。

### 2. 文章库 `src/lib/articles.ts`
- `ArticleListItem`：增加 `coverImage: string | null`。
- `ArticleInput`：增加 `coverImage?: string | null`。
- `mapArticle`：返回 `coverImage: row.coverImage`。
- `createArticle`：data 增加 `coverImage: input.coverImage ?? null`。
- `updateArticle`：data 增加 `...(input.coverImage !== undefined && { coverImage: input.coverImage })`（支持显式传 `null` 清空）。

### 3. API 层
- **src/app/api/articles/route.ts**：`CreateRequest` 增加 `coverImage?: string | null`，透传给 `createArticle`。
- **src/app/api/articles/[id]/route.ts**：`PatchRequest` 增加 `coverImage?: string | null`，透传给 `updateArticle`。

### 4. 后台 UI
- **src/components/admin/article-editor-dialog.tsx**：
  - 新增 `coverImage` 状态（初始化 `article?.coverImage ?? ""`）。
  - 在元信息区增加「封面图」区块：16:9 预览框（有图显示图片、无图显示「暂无封面」）、隐藏的 file input（`accept` 同正文上传，POST `/api/uploads` 后写入返回的 url）、URL 输入框、上传按钮、移除按钮（清空）。
  - `handleSave` 的 body 增加 `coverImage: coverImage.trim() || null`。
- **src/app/admin/articles/page.tsx**：文章列表行左侧增加小封面缩略图（有封面显示 40x40 圆角图，无封面显示浅色「无封面」占位）。

### 5. 前台渲染
- **src/lib/theme/content-renderer.ts**：
  - `ArticleData` 增加 `cover?: string`。
  - `dynamic-articles` 数据映射增加 `cover: a.cover ?? ""`。
  - `renderListField`：对 `mapKey === "cover"` 做图片化处理——目标是 `<img>`（或首子元素为 img 的元素）时 `setAttribute("src", value)`；值为空时执行「隐藏图片块」（移除 img；若其父容器无其他子元素且无文字，则连同空包装一起移除，避免留下高度占位）。
  - `article-body` 详情渲染：处理 `cover`——容器内若有 `[data-map="cover"]` 则填充 src / 无封面时移除；若文章有封面但容器内无封面占位，则在正文容器顶部注入一张带内联样式（`width:100%; max-width:800px; height:auto; object-fit:cover; border-radius; margin`）的封面图，保证现有主题的详情页顶部也能展示。
- **src/lib/blog.ts**：`toArticleData` / `toArticleDetailData` 增加 `cover: a.coverImage ?? ""`。

### 6. 主题生成提示词（可选增强）
- **src/agents/theme-agent.ts**（L389 附近）：补充约束——网格/多列卡片容器内的封面占位图需使用 `<img data-map="cover">`（有封面时填充、无封面时整块隐藏），使新生成的主题支持封面展示。

### 7. 测试
- **src/lib/theme/content-renderer.test.ts** 新增用例：
  - 列表卡片含 `data-map="cover"` 的 img + 文章有封面 → img src 为封面 URL。
  - 列表卡片含 `data-map="cover"` 的 img + 无封面 → 图片块被移除（含空包装）。
  - 详情有封面且容器无占位 → 顶部注入封面图。
  - 详情有封面占位 → 填充 src。
  - 详情无封面 → 无封面图残留。

## 四、Assumptions & Decisions（假设与决策）

- 封面 URL 以字符串存储，支持站内上传返回的 `/api/uploads/:id` 或外部 URL，直接复用现有上传接口。
- 无封面 → 图片块整体隐藏（用户已确认）。
- 展示位置 = 列表卡片 + 详情页顶部（用户已确认）。
- 列表卡片仅在主题模板含 `data-map="cover"` 时展示封面；对**已有主题**，若卡片无该占位则列表不显示封面（属主题结构限制），详情页通过注入兜底始终可用；新生成主题通过提示词更新支持。
- 主题中未打 `data-map="cover"` 的样例图片不在本次范围内处理。
