## 四、加载协议（决定「不要一次加载」能否落地）

`README.md` 开头必须写出以下协议（在全部背景介绍之前）：

1. **第一步只读本文件**，不要预读任何模块文档。
2. 用「业务域路由表」**只选 1 个**模块文档读取。
3. 模块文档给的是**结论 + 文件锚点**；要函数签名/实现细节时，按该模块末尾的「源码索引」用 Read 精确打开对应文件与行号，不要通读目录。
4. 跨域改动（如「加一个字段并渲染出来」）按 **data-and-api.md → 对应业务域** 读两个文件即可。
5. **禁止**：批量读取 `docs/knowledge/*.md`；把模块文档当源码替代品（只记「为什么/改哪里」）。

README 结构（≤180 行）：
- `## 加载协议（AI 必读）`：上述 5 条
- `## 业务域路由表`：`意图 | 模块文档 | 涵盖的关键文件`
- `## 高频问题速查`：约 10 条「现象 → 直接跳哪个文档的哪一节」，如：卡片点不动 → `theme-rendering.md#列表卡片与链接`；排版错乱/侧栏双倍偏移 → `theme-rendering.md#片段包裹剥离`；改 schema → `data-and-api.md#改-schema-的完整流程`；改 Key 不生效 → `platform-infra.md#配置缓存`；发布报未登录 → `content.md#掘金发布失败排查`
- `## 最小必要背景`：技术栈与版本风险、命令表（`dev/build/lint/test` + `juejin:login|publish|test-cookie`）、环境变量表、目录地图（`src/agents`、`src/lib`、`src/app`、`src/components/admin`、`prisma`、`scripts`、`.trae/documents`）
- `## 维护约定`：改代码后同步对应模块；新增模块需同时更新路由表

## 六、各模块必写要点（均已核对源码）

### ① `theme-generation.md`
**关键文件**：`src/agents/theme-graph.ts`、`theme-agent.ts`、`tools/image-search.ts`、`src/lib/theme/theme-session.ts`、`src/lib/theme/checkpoint.ts`、`src/app/api/themes/generate/route.ts`（含 `cancel/`）、`src/components/admin/theme-generate-dialog.tsx`（前端契约）
**要点**：
- 节点流向 `planner → skeleton → dispatch_pages →(Send)→ page_home|list|detail → validator → judge(可选) → revise ↔ 页面 → commit`。
- LangGraph 1.4.x：`Annotation` 用 `{ reducer, default }`（旧 `{ value }` 已弃用）。
- **Send 三条坑**：`dispatch_pages` 必须 `new Command({ update, goto: new Send(...) })` 并声明 `ends: [...]`（直接返回 `Send[]` 抛 `InvalidUpdateError`）；**子节点 state = Send payload**（不继承父 checkpoint），故需把 `userRequest/layoutHtml/pages/feedback/designBrief/siteConfig` 全量放进 payload；join 靠 `pages` 浅合并 reducer，validator 恰好跑一次。
- **单页重做（迭代）**：`routeFromStart` 在 `iteration` 下跳过 planner/skeleton；`makeDispatchNode` 只 fan-out `targetPage`；validator/audit 只遍历 `activePages`；`computeRevisePlan` 关闭 `skeletonFix`；`pages` reducer 浅合并保留非目标页；**从 input 注入上次快照开新 run**，不是 checkpoint 回放。
- **修订持久化**：`reviseCount`/`maxAttempts`(默认 1)/`scoreThreshold`(默认 60)/`judgeEnabled`；`ThemeMessage` 单表承载全部修订数据（`attemptIndex` 0=初始、1+=修订，`triggerError` 摘要如 `[list]样式不一致；[audit]头像重复；judge 65<70`，`htmlSnapshot`/`pageSnapshots`/`contentConfig` 快照，`metrics`），**每次 revise Send 后写一条**而非只在 commit；回滚 = 按 `attemptIndex` 取快照。
- **SSE 契约**：`POST /api/themes/generate` 的 `text/tool_call/stage/warn/page/metrics/done/error` 事件与 `metadata.langgraph_node → page` 映射；每次生成独立 `thread_id`；流结束后 `getState` 回放 `page`/`done`。
- 检查点：`SqliteSaver` 落 `dev-checkpoints.db`，仅用于断线恢复，与单页重做无关。
- 提示词硬约束（`theme-agent.ts`）：卡片封面用 `<img data-map="cover">`；禁图片素材；动态列表/标签/分类标记规则；同一页只允许一个文章流区块。
- 未接线代码：`src/agents/blog-agent.ts`（含 `tools/example.ts`）与 `tools/api-integration.ts` 当前无业务引用 —— 执行时用 grep 核实后标注为「示例/未接线」。
**素材**：`docs/architecture.md`；`.trae/documents/`：`主题生成多样性改造计划.md`、`token-optimization-theme-generation.md`、`theme-prompt-dedup-plan.md`、`theme-fix-style-quality.md`、`theme-style-chaos-fix.md`、`导航栏遮挡首页-原因分析与评分阶段识别修复计划.md`。

### ② `theme-rendering.md`（渲染 + 编辑侧）
**关键文件**：`src/lib/theme/{content-renderer,theme-splitter,layout-inject,content-extractor,style-analyzer,custom-pages,url-options,theme}.ts`、`src/lib/{blog,collections-render,markdown,field-registry,reusable-text,site-config}.ts`、`src/lib/types/content-config.ts`、`src/app/[...path]/route.ts`、`src/app/api/{themes,pages,reusable-text,urls,site-config,global-dynamic,debug}/**`
**要点**：
- 入口链路：catch-all `route.ts` → `getActiveTheme()`（无主题返回 `blogNotConfiguredHtml`）→ `renderCustomThemePage(route)` → `mergeThemePage` + `renderContent`；`renderContent` 按 `contentConfig` 的 `TextField/DynamicField/NavField` 分发，并做剪枝、头像去重、静态分类标签重建；`FEATURED_LIST_KEY = "featured-articles"`。
- **列表卡片与链接**（最易踩）：`renderListField` 对 `dynamic-articles` 且有内链的卡片用 **`display:contents` 的 `<a>` 包整卡**（不破坏 grid），并把卡内原 `<a>` 降级为 `<span>` 避免嵌套；降级必须 `while (inner.firstChild) span.appendChild(inner.firstChild)` 保留按钮文案，否则按钮变空。
- **静态分类/标签重建的风险**：`renderStaticTaxonomyLists` 用 `c.querySelector` 判定子项时不匹配自身，平铺的 `<a>` 列表会漏判；祖先遍历会爬到无 class 的 `div[data-page-host]` 被误当分类列表整体重建，导致**整页内容被替换/删除（表现为主题内容为空）**。约定：`isTaxonomyLink` 用 `matches || querySelector`；`isStructuralTaxonomyStop` 在 `body/html/main/header/footer/nav/data-page-host` 停止冒泡。
- **标记契约**：`h1-h6/p` 必须带 `data-content`；`data-map="body"` 必须在容器内且**不标** `data-content`；未标记文本由 `content-extractor.ts` 兜底打 `data-content-type="text"`；未标记元素文本与全局字段值相同时采用该全局 key（如 `blog-title`）而非类名派生 key；同 base key 且同文本复用 key，**不生成 `-N` 后缀**。
- **全局字段取值优先级**：渲染时优先取 `site_config` 表值 —— 若其中是占位符（"标题"/"站点描述"/"作者名"），会**覆盖主题 HTML 内嵌真实值**（「主题写好了却显示占位符」的根因）。
- **片段包裹剥离**：`stripRedundantFragmentWrappers`（`layout-inject.ts`，纯字符串、无 DOM 依赖）迭代剥离片段根部 `data-page-host` 或含 `page-content` 类的元素；必须在 `injectPageIntoLayout`（客户端预览）、`mergeThemePage`（服务端）、`buildPageBody`（生成源头）**三处统一调用**，否则预览与线上不一致（侧栏偏移翻倍）。
- **布局契约**：`ensureLayoutContract` 保证唯一 `[data-page-host]`、注入 `--nav-h` 与导航测量脚本；`THEME_SAFETY_CSS` 作为 `<head>` 最后一个 `<style>`（仅作用正文区，注释「勿手工修改」）；`ensureAvatarOverflow` 处理头像溢出。
- **一致性校验**：`validatePageFragment` 用 JSDOM 算页面类名与骨架类名重叠率，**阈值 ≥15%**；`style-analyzer.ts` 全确定性零 LLM 成本（`MIN_ROOT_VARS = 5`、`MAX_MISSING_CLASSES = 8`、`isPlainWhite`），产出 `skeletonIssues`(error)/`warnings`/`pageIssues`，error 级驱动 revise。
- **常量**：`BLOG_PAGE_SIZE = 10`、`HOME_PAGE_ARTICLE_LIMIT = 6`、`HOME_PAGE_TAG_LIMIT = 10`（首页标签云只出 Top 10）。
- **编辑侧**：`field-registry.ts` 是字段唯一事实来源（`GLOBAL_FIELDS` 9 个 / `STAT_FIELDS` 3 个 readonly / `EDITABLE_KEYS`），新增全局字段要同时改这里与渲染端；可复用文本存 `SiteConfig.textLibrary`（**不改 schema**），类型含 `source:"reusable-text"` 与 `textKey`，API 在 `src/app/api/reusable-text/route.ts`，绑定态下在库中编辑，**本地主题数据不会自动被覆盖**，须 UI 显式「加入库」并可跨主题共享（shared 徽标）；`custom-pages.ts#normalizeRoute` 归一化路径；`url-options.ts#getUrlOptions()` 产出 home/archive/category/tag/article/custom，仅取有文章的分类与标签；合集页 `collections-render.ts` 用 `jjc-` 前缀内置样式（点缀色 `#E5A83D`）与 `escapeHtml`。
- 测试：`content-renderer.test.ts`、`theme-splitter.test.ts`、`content-extractor.test.ts`、`style-analyzer.test.ts`、`collections-render.test.ts` 各覆盖什么。
**素材**：`.trae/documents/`：`内容区块缺失data-content标记修复计划.md`、`动态列表识别与标记优化计划.md`、`同文本data-content复用key修复计划.md`、`详情页冗余内容-样本文章残留修复计划.md`、`样式问题分析-导航栏遮挡与列表页横向排列修复计划.md`、`精选文章内置区块实现计划.md`、`可复用文本库功能计划.md`、`可复用文本锁定与博客设置统一配置.md`、`全局动态参数库复用功能计划.md`。

### ③ `content.md`（文章 / 元数据 / 画像 / 统计 / 掘金发布）
**关键文件**：`src/agents/article-agent.ts`、`src/lib/{articles,user-profile,article-stats,collections,juejin-tags,juejin-columns}.ts`、`src/lib/db/stats.ts`、`src/agents/juejin-publisher/**`、`src/app/api/{articles,collections,tags,categories,user-profile,juejin,juejin-config}/**`、`src/components/admin/{article-generate-dialog,article-editor-dialog,featured-articles-dialog,meta-manager-dialog}.tsx`
**要点**：
- 文章生成：`ArticleGenParams` 含 `authorProfile`（画像注入 prompt）；`POST /api/articles/generate` 为 SSE。
- 用户画像：基于**最新 20 篇已发布文章**生成，注入**文章生成与主题生成两处** prompt；数据与开关存 `SiteConfig.config`；`/api/user-profile` 的 GET/PUT/POST 分工。
- 统计：`bumpArticleRead` 阅读 +1 并累加 `SiteStats.totalViews`；`adjustArticleLike` 用「读-算-写」clamp ≥0 防漂移并同步 `totalLikes`；`setArticleCount` 维护 `totalArticles`。
- 标签/分类：`replaceAllTagsWith` slug 冲突追加数字后缀（`TypeScript` vs `typescript`）；`POST /api/tags/import-from-juejin` 为替换式导入，入口在 `meta-manager-dialog.tsx`（含二次确认）；标签选择 UI 为可搜索下拉（最多 50 条、可移除金色胶囊、默认展开）。
- 封面图：`Article.coverImage` 可置 `null` 显式清空；详情页有封面但正文无占位时注入到正文顶部。
- **掘金发布链路**：后台按钮 → `POST /api/juejin/publish` → 落临时 md → `spawn node publish.mjs` → 解析最后一行 JSON。登录态是**掘金 Cookie 字符串**（非 storage_state），AES 加密存 `site_config.config`；校验 `api.juejin.cn/user_api/v1/user/profile_id`，要求 `profile_id` 非空且 ≠ `"0"`。
- **掘金失败排查**：CodeMirror 不能 `fill()`，须「剪贴板 + Ctrl+V」，点击对 `.CodeMirror-scroll` 用 `force`；成功须识别 `/published` 重定向；点发布后**等「确定并发布」按钮出现**而非固定延时；标签至少 1 个、无则默认 `前端`、不存在的跳过、一个都没加上时兜底创建 `前端`；分类须在平台固定选项内否则回落第一个；专栏下拉定位用**原文 placeholder**「请搜索添加专栏，同一篇文章最多添加三个专栏」。
- **存在性判定**：以浏览器打开 `https://juejin.cn/post/<id>` 验证 `#article-root` 为主；`content_api/v1/article/detail`（数字 `article_id` + `aid=2608`）对非本人文章返回 404，**不可靠仅作兜底**；存在但找不到编辑入口 → **中止并提示用 `--force-new`**；`postId` 需回写内部维护；浏览器路径显式指向项目 `.browsers`。

## 八、Assumptions & Decisions

1. **不注册 Skill**：按用户选择只产出 `docs/` 文档；「SKILL 能看明白」由 README 的加载协议 + 路由表承担。

3. **不做操作手册**：参数表/点击步骤只在「常见任务」给最小必要说明，掘金部分直接链接既有 `SKILL.md`。
4. **模块收敛到 6 个**（v1 为 9 个）：把「主题编辑」并入 `theme-rendering`（同属主题内部机制），把「掘金发布」并入 `content`（同属内容生产链路），把「后台 UI」并入 `platform-infra`（同属平台表现层）。
5. **只保留一处附带改动**：`AGENTS.md` 追加 2 行入口提示；不改 `docs/architecture.md`。
6. **素材选取**：每个模块只引用直接相关的历史计划（见各模块「素材」），不搬运全部 27 篇。
