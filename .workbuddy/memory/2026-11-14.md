## 修复：新主题「主题 6 #2」统计条间隔错乱 + 作者头像显示 URL 文本

### 现象与实证
- 激活主题变为「主题 6 #2」(`704eb822…`, 深色工业风)，用户截图两处：归档页「全部归档」下方统计条右侧一大块深色空白、区块间隔异常；作者档案圆形头像里显示 `/api/up…3f82-` 字符串。
- 真实浏览器（Playwright + 本地 chromium，1280×900）复现：`.stat-strip` CSS `repeat(3, 1fr)` 但 HTML 有 4 个 `.stat-cell` → 第 4 项换行 (y=570)，右侧两列露出 `background:var(--line)`，统计条高 165px、hero 高 678px，把「全部文章」区块顶到 y=822。home 页同样 4 项 3 列。
- 渲染探针：list 页作者卡是 `<div class="avatar" data-content="author-avatar" data-content-type="text">`，`author-avatar` 是「text 类型但值为图片 URL」的全局字段，`renderTextField` 对非 img 元素写 `textContent` → URL 成可见文本；home/detail 页是 `<img>` 所以正常。头像 URL `/api/uploads/f0bc968e…` 实测 200 image/jpeg 80131B，图片本身没问题。

### 引入点
- 头像：老契约。`AVATAR_PLACEHOLDER`(theme-agent.ts L53) 与 `renderTextField` 的 img 特判自 monorepo 拆分 commit `31e2fe0` 起就在；11-11/11-13 统一头像识别口径时没覆盖「div 容器被 text 字段填充」这种组合。本次 LLM 受「禁止图片素材」规则影响把列表页头像写成纯 CSS 圆形 div 才暴露。
- 排版：LLM 生成时结构不匹配（3 列 + 4 项）。11-13 新增的 `LAYOUT_WIDTH_CONTRACT` 只约束「文章卡片网格」、`checkContentWidth` 对固定列数只报 warn，统计条漏网；不是改动把好排版改坏。

## 追修：hero 区排版「怪怪的」（面包屑紧贴 + 统计条 3+1 复现）

- 用户两张截图：① 面包屑「首页 / 归档」与「工业档案 / ARCHIVE INDEX」挤成一团；② 规格卡与「4 累计点赞」条带贴在一起、统计项孤行。
- 量化（Playwright 三档视口）：`.crumbs` 结束 y=184、`.hero-kicker` 开始 y=199（**间距 0**）；`gapHeroSpec=0`（spec-box 与 stat-strip 紧贴）；833px 视口下 `auto-fit minmax(240px,1fr)` 只排 **3 列** → 4 项 3+1 露白（785px/240=3.27）。即上一轮的 auto-fit 修复只在 ~1280px 有效，**中等宽度不彻底**。
- 改动：
  - `theme-splitter.ts`：`fixIncompleteGridRows` 兜底值由 `repeat(auto-fit, minmax(240px,1fr))` 改为 `repeat(N, minmax(0,1fr))`（N=静态子项数，任何宽度整齐一行；窄屏由主题 @media 覆盖）。坑：`count` 原在 `.some()` 回调内，replace 回调引用不到，需先取出 `itemCount`。
  - `theme-splitter.ts` THEME_SAFETY_CSS 增加 `:where()` 间距兜底（特异性 0，主题自有规则优先）：`.crumbs{margin-bottom:12px}`、`.stat-strip{margin-top:24px}`。
  - `theme-agent.ts` LAYOUT_WIDTH_CONTRACT 增补：固定列数必须整除子项数（4 项别用 3 列）；相邻区块垂直间距 ≥16px。
  - 线上 `themes.layout_html`（不依赖部署）：`.stat-strip` → `repeat(4, minmax(0,1fr))` + `margin-top:24px`；`.crumbs`（紧跟 `display:flex` 的那条）+ `margin-bottom:12px`。坑：宽松正则 `/\.crumbs\{/` 会命中 `.page-head .crumbs{ margin-bottom:22px }`，必须用 lookahead 限定 `display:flex` 那条规则。
