Objective
- 重构主题生成模块：主题固定包含首页/详情页/文章列表页，主题改为一页一行（ThemePage）维护，样式采用方案A+（共享布局含 nav/footer，页面只存正文），Agent 仍生成单文档、保存时自动拆分，旧主题数据直接重建。
Important Details
- 用户已确认三个决策：①样式用方案A增强——共享布局包含导航栏和页脚导航；②生成策略：Agent 生成一份 HTML，保存时自动拆分；③自定义页面也改为一页一行存入 ThemePage。
- 旧主题数据直接重建（migration 用 DROP TABLE），无需数据迁移脚本。
- 数据库实际位置：DATABASE_URL="file:./data/theme-sessions.db"（在 .env.local；根目录 dev.db 是空的）。
- 新模型：Theme（layoutHtml + contentConfig 共享） 与 ThemePage（type: home/list/detail/custom + route + html + contentConfig + sortOrder，@@unique([themeId, type, route])）。
- 拆分器原理：从完整文档抽出 nav/footer 与 head/style 为布局，布局中用 <div data-page-host=""></div> 占位正文；每页从原始文档 clone 后按 data-page-type 剪枝（复用 content-renderer 导出的 prune 函数）。
- 注意：LSP 持续报告 src/lib/theme.ts / src/lib/theme-session.ts 的错误，但这两个文件不存在，是陈旧诊断，可无视；只有 src/lib/theme/theme.ts 真实存在。
- npx tsc --noEmit 通过过一次（在 UI 修改前）；最后一次运行仅剩 admin/themes/page.tsx 的 HtmlEditorDialog 属性错误。
